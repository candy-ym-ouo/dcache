# DCache — 基于一致性哈希的分布式缓存服务

> **项目提示词**：分布式缓存：用 Go 基于一致性哈希实现缓存服务，支持 TCP 协议、TTL 过期、LRU 淘汰、多节点分片与节点增减时的数据迁移。

DCache 是一个纯 Go 标准库实现的分布式缓存系统，采用**一致性哈希（Consistent Hashing）** 对 Key 进行多节点分片，通过自定义 **TCP 二进制协议** 与客户端通信，内置 **TTL 过期**（惰性删除 + 定期清扫）与 **LRU 淘汰** 两种数据生命周期管理机制，支持 **节点动态增减** 以及增减节点时受影响 Key 的 **自动数据迁移**。

## 核心特性

| 特性 | 说明 |
| --- | --- |
| 一致性哈希分片 | 哈希环 + 每节点 160 个虚拟节点，节点增减时仅影响 `K/N` 的 Key |
| TCP 二进制协议 | 自定义定长头 + 变长负载帧格式，支持粘包/拆包处理 |
| TTL 过期 | 每条目独立过期时间；GET 惰性校验 + 后台周期清扫器主动清理 |
| LRU 淘汰 | 双向链表 + 哈希表实现，达到容量阈值时淘汰最久未访问条目 |
| 多节点分片 | 客户端按一致性哈希路由；服务端校验归属并返回 MOVED 重定向 |
| 数据迁移 | 节点加入/下线时，仅迁移归属发生变化的 Key，幂等、可续传、可中止 |
| 心跳健康检查 | 节点间周期心跳，超时判定为故障节点并触发集群视图更新 |
| 指标统计 | 命中率、QPS、容量水位、迁移进度等运行指标，供 Web 控制台展示 |
| Web 控制台 | 简单前端（原生 HTML/CSS/JS），可视化查看拓扑、键、指标并操作节点 |
| 零依赖 | 仅使用 Go 标准库，单二进制部署，跨平台 |

## 目录结构（规划）

```
dcache/
├── main.go                      # 启动入口：解析配置，拉起 TCP / HTTP / 集群模块
├── internal/
│   ├── config/                  # 配置加载与校验
│   ├── protocol/                # TCP 二进制协议编解码、命令定义
│   ├── server/                  # TCP 服务端、连接会话、命令分发
│   ├── cache/                   # KV 存储、缓存条目、TTL、LRU、缓存门面
│   ├── hash/                    # 一致性哈希环
│   ├── cluster/                 # 节点信息、集群管理、数据迁移、心跳
│   ├── client/                  # Go 客户端（含连接池、哈希路由）
│   ├── metrics/                 # 运行指标统计
│   └── web/                     # HTTP API 与静态资源服务（前端入口）
└── web/                         # 前端页面（HTML/CSS/JS，由 Go embed 内嵌）
```
